A program that writes one kind, funny fortune for a houseplant in 120 characters or fewer — a prediction for the plant on the windowsill, judged by a gardener. Entry for make.fun's "Fortune in a Pot" bounty.

## Run it

```sh
node main.ts
```

The program writes the fortune to `/output/entry.txt`.
